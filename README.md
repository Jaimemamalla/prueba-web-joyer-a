# Nácar, joyería de barrio

Práctica 1 de Maquetación Web con Hojas de Estilo (UDIT, 4º). Web de un comercio de barrio: una joyería.

Autores: Martina y Jaime.

## Qué hay

- `index.html`: estructura, librerías y sistema de diseño de Tailwind (`@theme`).
- `styles.css`: hoja de estilos propia con `@layer` y animaciones `@keyframes`.
- `script.js`: animación de scroll. El scroll controla un vídeo de un diamante girando.
- `media/`: aquí va el vídeo `diamante.mp4` (ver `media/LEEME.txt`).

## Tecnologías

- Tailwind CSS v4 (Play CDN)
- GSAP y ScrollTrigger
- Lenis (scroll suave)

## Cómo verlo

Abre `index.html` en el navegador con conexión a internet, porque las librerías y las fuentes se cargan desde CDN.

Para que el vídeo cargue sin problemas, mejor usar un servidor local, por ejemplo la extensión Live Server de VS Code.
